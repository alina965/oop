# ООП на C++
## LAB0 
### Раздельная компиляция и пространства имен (namespaces)
Программа принимает в качестве аргумента имя текстового файла, и выводит CSV файл с колонками:
- Слово.
- Частота.
- Частота (в %).
CSV файл упорядочен по убыванию частоты. Разделителями считаются все символы кроме букв и цифр.
Аргументы командной строки программы:
> word_count.exe input.txt output.csv
## LAB1
### Битовый массив
Программа реализует класс `BitArray` для работы с битовыми массивами. Класс предоставляет методы для создания, изменения размера, битовых операций (AND, OR, XOR, сдвиги) и проверки состояния битов. Реализация включает обработку граничных случаев, исключений и покрытие юнит-тестами. Класс также поддерживает строковое представление массива и сравнение объектов. Публичные члены класса задокументированы.
## LAB2
### Игра “Жизнь”
Программа реализует клеточный автомат Conway’s Game of Life с поддержкой различных правил перехода и работы в интерактивном/оффлайн-режимах.
Основные особенности:
1. Чтение и запись конфигураций из файлов формата Life 1.06 с обработкой правил (`Bx/Sy`), имени вселенной и начального состояния.
2. Три режима работы:
    - Интерактивный
    - Случайная инициализация (предустановленные паттерны).
    - Оффлайн-режим (автоматический расчёт и сохранение после N итераций).
3. Тороидальное поле (края соединены).
## LAB3
### Гибкая система событий с Observer и PIMPL
Программа реализует гибкую систему событий на основе паттерна Observer, позволяя подписываться на события разных типов данных с помощью шаблонов.
Ключевые моменты:
- IObserver<T> — интерфейс для наблюдателей, обрабатывающих события типа T.
- Subject<T> — управляет подписками (attach/detach) и уведомляет наблюдателей (notify).
- PIMPL скрывает реализацию Subject (хранение наблюдателей в SubjectImpl<T>).
- Готовые наблюдатели: ConsoleObserver<T> (вывод в консоль) и LoggingObserver<T> (запись в файл).
